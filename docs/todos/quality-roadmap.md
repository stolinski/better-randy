## Reality-check findings (2026-05-29, adversarial 5-agent audit)

Grounded "how close to the dream tool" audit. **Bottom line:** the engine substrate is genuinely real (WebGPU/TypeGPU compositor, WICG HTML-in-Canvas capture, transparent 4K export config, frame-determinism, a substantive safety linter, a probe-backed adversarial Critic). The honest gap is (1) the **corpus** — 1 ship-grade preset against ~15 families — and (2) **structural Pack Roles** — color + font re-skin works end-to-end, but edge/depth/light/material Roles are declared-but-dead (`resolveStyle`/`resolveRole` have zero render-time callers) and no shipped preset has rendered under a non-syntax Pack. The work is bounded execution, not unknown research. Three concrete issues surfaced + status:

- [x] **Export froze DOM-driven content (real bug, FIXED).** The export `renderFrame` advanced the timeline (mutating the DOM) but never re-captured it — `uploadDom()` was absent — so `render()` sampled a stale `domTexture`. Split-text kinetic typography + the surface enter/exit slide froze in exported video, while shader-uniform content (marks/focal/visibility) animated correctly. Confirmed empirically (DOM word-units moved −14→−249px across progress) and by code. Fix: `Workspace.svelte` export `renderFrame` now calls `activePipeline.uploadDom()` after `progress()` / before `render()` (synchronous, queue-ordered ahead of the render draw — mirrors the proven preview onpaint path). svelte-check clean.
- [~] **No export-output verification existed (partially closed).** Added `scripts/probe-frame-diff.ts` (pngjs): asserts a frame sequence animates (consecutive frames differ) + carries alpha; exits nonzero on frozen/no-alpha. Self-tested on captured frames (detects animation; correctly flags screenshots as alpha-less). **Still open:** a true decode of an exported WebM/ProRes file — WebGPU canvas readback returns blank, so real export frames must come from the encoder output. The probe is ready to consume them once a frame-dump path exists.
- [x] **Critic/Producer bound to a dead `docs/aesthetic.md` stub (FIXED).** A fresh Critic following the skill verbatim loaded a 931-byte redirect → zero aesthetic rules, so every `aesthetic-miss` could slip through. Repointed every reference in `.claude/skills/{critic,author,brainstorm}`, `.claude/commands/{critic,author,brainstorm}`, and `docs/quality-rubric.md` to `docs/packs/<pack>/aesthetic.md` (matching `docs/critic.md`'s resolution).
