# `washi-tape` Overlay

Washi-tape strips anchor collage-card corners across the channel's aesthetic (`docs/aesthetic.md` § Collage System / Tape) — semi-transparent multiply blend at ~0.6 alpha, 5–25° rotation, palette-pull color, grain texture so they don't read as flat plastic. We modeled tape as its own **Overlay** Pipeline (`washi-tape`) rather than baking it into a Surface or expressing it as an Effect. Schema is `{ color?: string, rotation?: number, length?: number }`: color defaults to channel yellow `#fabf47`, rotation is bounded 5–25°, length is in canvas pixels at 4K (width is fixed by the aesthetic-correct ratio). Multiply-blend + grain are carried by the CanvasSource's CSS (`mix-blend-mode: multiply; opacity: 0.6` + a stacked `repeating-linear-gradient` for fiber texture) so the v1 ships without a `shaderPass`; if pixel-quality torn ends become a requirement, the `OverlayRenderer.shaderPass` slot from ADR-0005 is the upgrade path.

## Considered options

- **Bake tape into the Surface chrome** (rejected: tape is a *placement choice* that varies per Preset — top-left corner here, bottom-right elsewhere, two strips on a different card — and the Surface should not carry per-preset placement state. Overlay is the layer with `position: { anchor, offset }` for this exact reason).
- **Model tape as an Effect** (rejected: effects are scene-content-agnostic post-process passes per `engine-architecture.md`. Tape is a *renderable element with placement* — it has an anchor, an enter/exit transition, and per-instance content (color, rotation, length). Those are Overlay invariants, not Effect ones).
- **Skip the schema entirely and let presets author tape inline in the Surface CanvasSource** (rejected: the channel reuses tape across many future Briefs — pullquote-on-photo cards, modern web-article tear-outs, photographed-frame corners. Pulling it into the registry once means every consumer composes against the same content shape).
- **Make `rotation` seeded rather than schema-authored** (rejected: tape rotation is a *deliberate authoring choice* — a 5° tape reads as "carefully placed," a 23° tape reads as "thrown on" — that the Preset should set explicitly. Seeded jitter belongs to physical-imperfection details like torn-edge paths and registration offsets per Q6 / G9, not to authorial composition choices).
- **Hardcode color to channel yellow with no override** (rejected: aesthetic.md § Collage System / Tape says tape color is a palette pull at low saturation — yellow, teal, red. A schema-optional `color` field with a yellow default lets presets vary palette without forcing every consumer to repeat the channel-yellow string).

## Consequences

Adds one folder `src/lib/pipelines/overlays/washi-tape/` (index + CanvasSource + Editor) and one registry slot in `PIPELINE_REGISTRY.overlays.washiTape`. The grit overlay stays composition-wide via `paper-grain` in `effects.frame` — tape's grain texture is *its own* fiber pattern (procedural CSS), not the composition's paper noise. First consumer is `src/lib/presets/segment-title-card.json`, which anchors one yellow strip at the top-left corner of the newspaper card per ADR-0008. The 5–25° schema bound enforces aesthetic.md § Tape's stated range; presets attempting a 0° or 45° tape fail schema validation, which is the intended behavior — a tape strip outside that range no longer reads as washi tape, it reads as a printed band.
